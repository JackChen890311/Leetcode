- 有趣的題目，感謝提示區的老哥，不然我想不出來：
	- 90 = transpose + reverse row  
	- 180 = reverse row + reverse column  
	- 270 = transpose + reverse col
- Transpose: `matrix[i][j] = matrix[j][i] for i in range(N) for j in range(i, N)`
- Reverse: Use [[Two Pointers]] `matrix[i][s], matrix[i][e] = matrix[i][e], matrix[i][s] for i in range(N)` for reverse row, if col swap 2 dimensions
