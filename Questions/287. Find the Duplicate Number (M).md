- [If Programming Was An Anime](https://www.youtube.com/watch?v=pKO9UjSeLew&)
- 快慢指針找環的起點：當兩指針遇到時，把其中一個丟回起點，兩個指針一樣速度移動，再遇到時就是環的起點
- 在這題的條件下，可以把原始 Array 想像成一種 Mapping 或是 Graph: `i -> nums[i] -> nums[nums[i]]`
- 如果有重複的數字代表會有環，再用找起點的方法就可以找到是哪個數字重複
