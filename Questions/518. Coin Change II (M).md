- 2D DP: 
	- 先對每個 coin，再對每個 amount
	- 針對每個 `dp[i][j]` 檢查所有可能的方法數（如果可以透過拿這個 coin 達到這個 amount，就把方法數加進去）
	- 注意 unbounded 的話內迴圈用順序（可以重複拿），bounded 的話用倒序（不能重複拿）
	- 這樣才不會重複算到拿法（[[70. Climbing Stairs (E)]] 這種是 [1,1,2] != [1,2,1]，但這題是）
```python
class Solution:
    def change(self, amount: int, coins: List[int]) -> int:
        # unbounded knapsack problem
        # 2d dp with one dp array
        if amount == 0: return 1
        dp = [0] * (amount + 1)

        for c in coins:
            if c > amount: break
            dp[c] += 1
            for j in range(c, amount + 1):
                # if have path, add the number of path to it
                # range(c, amount + 1) since it's unbounded (can choose more than once)
                dp[j] += dp[j - c]

        return dp[amount]

```
