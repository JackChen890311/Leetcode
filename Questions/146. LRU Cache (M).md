### Notes:
- 標準做法：Hash + Doubly Linked List，[Reference](https://en.wikipedia.org/wiki/Cache_replacement_policies#LRU)
- Node 要記錄 key, value，Hash 裡面記錄的是 key: Node
- 當 get 的時候，把該 Node 塞到最前面
- put 的時候，如果超過上限，移掉最後面的，同時 put 的也要放到最前面
- 其實我覺得這題蠻爛的，但好像是常考題
