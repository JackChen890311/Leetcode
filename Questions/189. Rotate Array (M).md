### Notes:
- 有趣的題目，一開始用 O(N) time + space 解決，直接從 index 判斷再從複製的 array 找值
- 後來看提示才知道怎麼用 O(1) space 解決：用 reverse 的概念，有趣
```python
class Solution:
    def rotate(self, nums: list[int], k: int) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        if k == 0: return
        N = len(nums)
        k %= N

        # [1,2,3,4,5,6,7] k = 3
        # [5,6,7 | 1,2,3,4]
        # [7,6,5 | 4,3,2,1]

        def reverse(array, s, e):
            while s < e:
                array[s], array[e] = array[e], array[s]
                s += 1
                e -= 1

        reverse(nums, 0, N-1)
        reverse(nums, 0, k-1)
        reverse(nums, k, N-1)
```
