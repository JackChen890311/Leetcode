### Notes:
- 標準 DP，`dp[i][j] = (s[i] == s[j]) and (j == i + 1 or dp[i+1][j-1])`，j == i + 1 作為 base case，要注意 base case 的建立要對
- 結果 base case 只要到長度為 2 就好了，後面的都可以 DP
```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        N = len(s)
        dp = [[False] * N for _ in range(N)]
        result = s[0]

        for i in range(N):
            dp[i][i] = True
            for j in range(i):
                # i = 0, j = x
                # i = 1, j = 0
                # i = 2, j = 0, 1
                if s[i] == s[j] and (i - j == 1 or dp[j+1][i-1]):
                    dp[j][i] = True
                    if i-j+1 > len(result):
                        result = s[j:i+1]
        
        return result
```
