### Notes:
- Frequency 要從大做到小，但 Cooling Time 是從最近的做比較好
- 寫出一個 AC 但超慢：用 Heap 紀錄剩下次數，每輪從最大開始檢查是否可以做，不行就往後找，同時用另一個 Hash 來紀錄上次做的時間
- 可以用 Heap + Queue 來做，好屌，Queue 裡面是冷卻中的 task，會按照時間先後排列，直到冷卻完才會被推回 max_heap，這樣就不用 Hash 了，聰明
```python
class Solution:
    def leastInterval(self, tasks: List[str], n: int) -> int:
        freq = Counter(tasks)
        max_heap = []
        for task in freq:
            heapq.heappush(max_heap, -1 * freq[task])
        

        timer = 0
        q = deque()
        while max_heap or q:
            if max_heap:
                maximum = heapq.heappop(max_heap)
                maximum += 1
                if maximum < 0:
                    q.append((maximum, timer + n))
            if q and q[0][1] == timer:
                frequency, time = q.popleft()
                heapq.heappush(max_heap, frequency)
            timer += 1
        return timer
```
- 最快解可以用算的：所需時間是最大次數的 task 間隔 n 後的結果，因為其他的都可以塞在他中間，加上如果有多個一樣大的就平移一格，並且至少會需要 len(tasks)
```python
```python
class Solution:
    def leastInterval(self, tasks: List[str], n: int) -> int:
        frequencies = Counter(tasks)
        max_frequency = max(frequencies.values())
        number_with_max = sum(
            count == max_frequency
            for count in frequencies.values()
        )

        required_slots = (
            (max_frequency - 1) * (n + 1)
            + number_with_max
        )

        return max(len(tasks), required_slots)
```
